## Problem

I wanted a complete arcade loop — movement, combat, resources, base building, and score — without a bundler or game framework. The constraint was the point: **pure ES modules** that run as authored.

## Approach

**Bee Brave** is a top-down shooter in a hexagonal hive world. You defend honeycomb cells from invading bees and elite hunters while collecting honey to grow the hive. Special weapons, heavy ordnance drops, and defensive tech deepen the combat loop. The run ends when hive cells are destroyed; high score saves locally.

Controls stay keyboard-first (WASD / arrows, Space, specials on `V` / `B` / `C`).

## Outcome

A shippable pure-code canvas game that doubles as a performance and architecture reference for “how far can vanilla go” before reaching for a framework.
