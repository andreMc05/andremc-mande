Large applications pass data, events, and side effects through nested layers the same way Russian nesting dolls stack. An outer screen fails because an inner doll—an event handler, a library callback, a state update, or a dependency quirk—fired at the wrong moment or returned the wrong value. Text prompts and single screenshots show one doll. They do not show the order in which the dolls open.

A short screen recording supplies that order. It records the exact frame where a spinner hangs after a successful network response, the animation that collides with a click handler, or the layout shift that only appears after a specific sequence of interactions. Several existing tools already convert that recording into structured input an agent can act on:

- Framesleuth (local-first, Apache-2.0, MCP-ready) processes frames, console output, network activity, and narration into an evidence-cited Context Bundle. The agent receives ranked file:line candidates grounded in the video rather than a free-text description.
- The video-debug agent skill uses ffmpeg scene detection to extract only the frames where the screen changes, then hands those frames plus a timeline to Claude Code, Cursor, or similar agents so they can correlate a visual glitch to code.
- clip.qa records a phone session and produces a structured bug report with reproduction steps, expected versus actual behavior, and device context formatted for direct paste into Claude Code or Cursor.
- Replay analyzes video for temporal behavior (state transitions across frames) rather than static pixels, then supplies agents with structured UI and flow data that static screenshots lack.

SessionSolve and similar experimental pipelines take the same idea further by loading the full repository alongside the video so the model can link a visual failure to a specific code path, generate a patch, and produce a regression test derived from the recorded actions.

Once the harness exists—MCP tools, agent skills, or a local pipeline that maps video evidence back into the codebase—the model can examine the sequence instead of reconstructing it from a written report. You still narrow the scope to a feature or module. You then ask for explicit verification steps so the proposed change can be checked against the original behavior. The nesting does not disappear; video simply lets the agent watch the dolls open in order and identify which layer is out of sync.
